# Break App V2

Gestion des demandes de pauses avec comptes individuels et pilotage.

Pour ajouter un conseiller : créer son compte dans Supabase Authentication, puis le renseigner dans Pilotage → Conseillers et accès, avec son équipe et le rôle Conseiller. Un compte Auth seul ne donne pas accès aux pauses.

Ce dépôt contient les fichiers compilés du site. La préproduction reste séparée.
